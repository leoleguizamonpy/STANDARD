## Ecosystem audit

STANDARD v1.0.0 was contrasted against engineering patterns present in:

- TOURNA
- ACTIO
- LEOLEGUIZAMON
- SEOT
- BrandADN

This audit produced material corrections before certification:

1. Git flow became configurable (`mainline` or `develop`) instead of imposing a permanent integration branch universally.
2. authority became scoped by responsibility instead of one flat document hierarchy.
3. formal certification became bound to an exact commit/HEAD.
4. project-specific domain rules were explicitly excluded from the universal standard.

See `docs/audit/ECOSYSTEM_PATTERN_MATRIX.md`.

## Deferred capabilities

The following are not part of v1.0.0 certification and must not be presented as implemented:

- `saas` profile
- `ai-system` profile
- automatic migrations between STANDARD versions
- advanced stack-specific architecture scanners
- published npm CLI/package distribution
- advanced stack generators
- committed lockfile/frozen-install enforcement

## Certification rule going forward

This document records historical evidence. Future commits do not automatically inherit certification. A new release candidate must pass the applicable gates on its own exact revision and follow the release process defined by STANDARD.
